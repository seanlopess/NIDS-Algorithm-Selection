# Algorithm Selector for Network Intrusion Detection Systems

This project focuses on evaluating and selecting the most suitable machine learning algorithm 
for Network Intrusion Detection Systems (NIDS) using a benchmark military network dataset.

## Algorithms Used
- K-Nearest Neighbors (KNN)
- Decision Tree
- Logistic Regression
- Random Forest

## Features
- Feature selection using Random Forest
- Hyperparameter tuning using Optuna
- Performance evaluation using accuracy, precision, recall, and F1-score

## Tools & Technologies
- Python
- Scikit-learn
- Pandas, NumPy
- Optuna
- Power BI (for visualization)

## Dataset
NSL-KDD / Military Network Intrusion Dataset

## How to Run
1. Install dependencies  
   `pip install -r requirements.txt`
2. Run the notebook or scripts

## Outcome
The project identifies the best-performing algorithm for intrusion detection 
based on evaluation metrics.
